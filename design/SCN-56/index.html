SLAY CITY Native primitives

The six primitives design/SCN-5 does not cover — Section, Grid, ScrollScreen, ProgressBar, CurrencyAmount, StreakBadge — taken from rubanwd/slay-city@beba39d. Tokens, type scale, SlayButton, SlayCard and AppContainer are in design/SCN-5/index.html and are not repeated. Machine-readable values: <script id="slay-primitives-spec"> at the top of this file.

Before you implement

Twelve places where the SCN-56 prompt and the code disagree, or where the prompt is silent.

D1 · Scope

Prompt saysNine primitives: SlayButton, SlayCard, Section, Grid, AppContainer, ScrollScreen, ProgressBar, CurrencyAmount, StreakBadge.

Do insteadSlayButton, SlayCard and AppContainer ALREADY EXIST (SCN-5, src/components/). Do not rebuild them — check them against design/SCN-5/index.html and fix only gaps. Build the other six.

Rebuilding would duplicate SCN-5 and risk drifting from its approved reference.

D2 · Icons

Prompt saysCurrencyAmount and StreakBadge use the icons already ported.

Do insteadThey are NOT ported. `npx expo install react-native-svg`, then add src/components/ui/CoinIcon.tsx and XpIcon.tsx from the exact paths in spec.icons.

react-native-svg is not in package.json and no icon component exists in src/.

D3 · Coin colours

Prompt saysUse only the brand colors; nothing hard-coded outside the tokens.

Do insteadAdd an `artwork.coin` namespace to packages/tokens — rim #E0A11B, face #FFCE45, starShadow #7BB800 — and use it only in CoinIcon. The star itself is lime-green from the brand palette.

The coin is an illustration drawn with gold that the UI palette does not have. Naming the values keeps them out of components without pretending they are brand colours.

D4 · Palette size

Prompt sayssix brand colors

Do insteadSeven tokens plus the `surface` neutral (#1A1A1A), as in SCN-5.

AGENTS.md lists seven, including neon-orange.

D5 · StreakBadge gradient

Prompt says(not mentioned)

Do instead`npx expo install expo-linear-gradient` — the badge fill is a left-to-right purple→cyan gradient.

Not in package.json; NativeWind cannot express a gradient fill.

D6 · Unused on the web

Prompt says(not mentioned)

Do insteadGrid and StreakBadge are used on NO web screen (StreakBadge appears only in its Storybook .mdx). Build them faithfully but keep them small; do not spend effort on the hover-only tooltip.

Measured: 0 screen usages of each in rubanwd/slay-city.

D7 · Grid widths

Prompt says(not mentioned)

Do insteadCompute each cell's width from the ACTUAL gap: (containerWidth − gap × (cols − 1)) / cols. Support only the equal-columns behaviour; the web's `grid` flag and flex mode then render the same.

The web's flex mode hardcodes widths for the md gap (calc(50% − 0.375rem)); any other gap wraps or leaves space. A web bug, not a design.

D8 · ScrollScreen on native

Prompt saysHandle safe areas in ScrollScreen and AppContainer.

Do insteadScrollView filling the screen; bottom content padding = tab bar height + bottom inset (useBottomTabBarHeight), not the web's fixed 150px. The web's --screen-top-offset (the admin view-as banner) becomes a topOffset prop. A `footer` stays pinned below the scroll area.

On the web the nav is a fixed overlay, so content needs a fixed clearance. A native tab bar reports its own height.

D9 · ProgressBar identity

Prompt says(not mentioned)

Do insteadThis is src/components/ui/ProgressBar (labels, glow, animated fill). The mission header bar is a DIFFERENT component, features/mission/ProgressBar — out of scope, do not merge them.

The web keeps both; only the placement test uses the ui one today.

D10 · ProgressBar animation

Prompt says(not mentioned)

Do insteadAnimate with Reanimated on the UI thread: 600ms, easing bezier(0.4, 0, 0.2, 1), from 0 on mount when `animate` (default true). Prefer scaleX with transformOrigin 'left' over animating width.

The web animates `width`; AGENTS.md here forbids animating layout properties when a transform works.

D11 · Coin text colour

Prompt says(not mentioned)

Do insteadCoinAmount's number INHERITS the surrounding text colour; only the icon is gold. XpAmount's number is cyan.

The web component's comment says coins default to gold, but its classes set no colour. Code wins over the comment.

D12 · StreakBadge tooltip

Prompt says(not mentioned)

Do insteadTap toggles the tooltip; it auto-hides after 3s or on the next tap. Web shows it on hover/focus only.

There is no hover on a phone. Derived for native — marked as such.
